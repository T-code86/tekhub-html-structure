# TEKHUB Examination Portal UI

I created the structure of a landing page for the TEKHUB examination portal in HTML. The page includes a hero section on the left with the TEKHUB logo, introduction text, and exam guidance icons, while the right side contains the candidate login form with fields for the PIN and serial number. I also styled the layout using basic CSS to center the page, reset default spacing, and improve the overall presentation of the interface.
